## Documentation contract

Public docs use English, avoid personal paths and customer identities, and distinguish available
behavior, optional configuration, and planned work. Historical audits and implementation records
are evidence for maintainers, not public navigation. See
[open-source readiness](release/open-source-readiness.md) for the remaining public-visibility gate.
