# F10.1 Maker Report -- License and Distribution Metadata

## Scope delivered

The eBrain-authored repository surface now declares `AGPL-3.0-only` consistently:

- Root `LICENSE` is the verbatim GNU Affero General Public License version 3 text, obtained from
  `https://www.gnu.org/licenses/agpl-3.0.txt`. Its SHA-256 is
  `0d96a4ff68ad6d4b6f1f30f713b18d5184912ba8dd389f86aa7710db079abcb0`.
- Root package metadata, README badge/footer, and contributor terms use the same SPDX identifier.
- `THIRD_PARTY_NOTICES.md` distinguishes eBrain's root license from the separately obtained
  upstream knowledge engine and direct dependency. It states that the installer/CI clone the
  engine at a pinned revision into ignored local `vendor/` state, rather than falsely presenting
  it as a tracked AGPL subtree.
- The prior F10.0 audit was corrected to describe that verified distribution fact.

No upstream source file, notice, or license was modified. No agent CLI or provider service is
bundled or relicensed. This phase makes no public repository, push, tag, registry publication, or
deployment action.
