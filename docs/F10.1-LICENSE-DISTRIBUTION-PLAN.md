# F10.1 Implementation Plan -- License and Distribution Metadata

## Decision

The eBrain-authored repository surface will be licensed as `AGPL-3.0-only`. `LICENSE` will be the
verbatim GNU Affero General Public License version 3 text from GNU's canonical publication. Package
metadata, README badge/footer, contributor terms, and public release documentation will use the
same SPDX identifier.

This phase changes repository licensing metadata only. It does not publish the repository, offer
legal advice, relicense third-party work, change agent/provider behavior, or resolve the F10.0
public-history and operator-specific-isolation blockers.

## Distribution facts to preserve

1. Root source is eBrain-authored and carries the root AGPL-3.0-only declaration.
2. The installer and CI obtain the knowledge engine from its upstream repository at a pinned
   revision into ignored local `vendor/` state. It is not a tracked subtree or a claim that eBrain
   redistributes upstream source under AGPL.
3. Direct runtime dependencies and any separately obtained upstream engine retain their own
   upstream terms. A root license change does not alter those terms.
4. `THIRD_PARTY_NOTICES.md` will describe the boundary, upstream license attribution, and the
   location of the authoritative upstream notices without copying or modifying them.

## Implementation blocks

### Block A -- Canonical root license

- Replace the root MIT text with the exact GNU AGPL v3 text obtained from GNU's canonical source.
- Set root `package.json` to `"license": "AGPL-3.0-only"`.
- Add an integrity regression test that validates the exact expected AGPL text digest, title, and
  SPDX metadata. The test operates only on tracked public files.

### Block B -- Public metadata and attribution

- Update README badge/footer and all root public contribution language to AGPL-3.0-only.
- Correct the upstream-engine description: it is installed/cloned at a pinned revision and retains
  its upstream MIT license; it is not represented as a tracked vendored subtree.
- Add `THIRD_PARTY_NOTICES.md` for the upstream engine and direct runtime dependency boundary.
- Update the F10.0 audit wording to match the verified ignored-vendor distribution fact.

### Block C -- Verification and release boundary

- Run the focused license contract, contributor/public metadata scans, full CLI and TUI suites,
  shell syntax, diff check, and secret scan.
- Ensure no root public file still presents MIT as the eBrain license. References to upstream MIT
  remain only in third-party attribution contexts.
- Record the official source URL/digest in the maker report. An independent checker must verify
  exact license text, metadata consistency, notice boundaries, and no claim that public-release
  blockers are closed.

## Stop conditions

Stop for a legal/owner decision if an upstream component is found tracked under incompatible terms,
if a requested distribution bundles code without a clear license notice, if a root file requires an
ambiguous `or-later` choice, or if a public release action is requested. Do not infer permission to
rewrite history, push, tag, publish, change repository visibility, or deploy a website.
