# F10.3 Static Documentation Website -- Maker Report

## Scope delivered

- Added an isolated, private `website/` Astro package configured for static output only.
- Kept the public Markdown tree as the source of truth through a build-time allowlist; the website
  adds routes, navigation, local search, and presentation but no copied documentation body.
- Expanded public developer documentation with quick start/onboarding, manual and guided launch,
  sessions, context packs, episodes, procedures/workflows, task signals, profiles/targets, TUI,
  diagnostics, memory, workspace/session, and routing/cost command references.
- Built a documentation-first home, four-path documentation hub, desktop/sidebar/heading-index
  reading shell, mobile disclosure navigation, adjacent-page flow, and keyboard search.
- Synced only committed wordmark/TUI SVG assets and a small local icon subset. Footer links use the
  official eBrain GitHub repository and the supplied X/LinkedIn destinations.
- Added source and output contracts for route parity, static-only configuration, no deploy adapter,
  local assets, local link resolution, Markdown-link rewrite, and public privacy patterns.
- Ignored generated Astro cache and static output. No Vercel project, deploy configuration, preview
  URL, push, visibility change, release, or external submission was created.

## Design and safety decisions

Herdr was studied only for developer-documentation interaction patterns: product/docs separation,
fast paths, sidebar navigation, heading index, keyboard search, reading flow, and compact source
links. No text, screenshots, brand, feature claims, or visual identity were copied. The resulting
site uses eBrain's dark terminal-derived palette and repository-owned visual assets.

The website deliberately does not turn task signals into a model recommendation, report a
subscription as usage, expose personal filesystem paths, include historical operator artifacts in
navigation, or make universal provider-performance claims. It remains local/static until a release
owner separately approves publication.

Mobile visual QA found that the HTML SVG height attribute overrode its intended proportional layout
when CSS only set width. `height: auto` now preserves the terminal proof's intrinsic aspect ratio at
narrow widths.
