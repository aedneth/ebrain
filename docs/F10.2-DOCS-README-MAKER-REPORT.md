# F10.2 Maker Report -- Public Docs and Native Assets

## Scope delivered

- Replaced the root README with an English, source-first public introduction: product boundary,
  five-minute local proof, daemon/MCP model, workspaces/sessions, governed routing, factual token
  telemetry, CKIS relationship, supported adapters, safety boundary, contribution, attribution,
  and AGPL terms.
- Added an explicit public-doc navigation tree for getting started, concepts, architecture, guides,
  reference, and release material. It is intentionally separate from historical handoffs, audits,
  and detailed ADR records.
- Added repository-owned pixel wordmark and sanitised TUI demo assets. The demo is generated from
  the production pure frame renderer and a fixed fixture; it contains no terminal escape sequence,
  local path, prompt, credential, customer identity, session output, or live telemetry.
- Added `bun run docs:assets` for deterministic regeneration and a documentation contract test.
  The contract resolves all local links, constrains them to the public allowlist, prohibits internal
  navigation, and rejects private-path, dotenv, token-shaped, and emoji regressions in public copy.
- Updated contributor setup and public workflow links to avoid private operator instructions.

## Decisions and boundaries

Public architecture decisions are now concise summaries rather than links to historical ADR files.
This is deliberate: the F10.0 gate still says historical operator material is not automatically
public-safe. The documentation describes supported local behavior and configured/planned boundaries;
it does not claim a published release, deployed website, embedded shell, live benchmark ranking, or
universal model recommendation.

This phase writes local source, generated SVG, tests, and documentation only. It did not change
repository visibility, push a commit, create a release/tag, publish a package, call a provider, or
deploy a website.

## Verification performed by maker

- Inspected the generated native-size wordmark and 1018x533 TUI frame visually. The frame was

- Final suites after F10.2 changes: `bun test ./cli/` -> `277 pass, 0 fail`; and
  `bun test ./tui/test/` -> `442 pass, 0 fail`.
- `bash -n cli/ebrain scripts/install.sh`, `git diff --check`, the TUI zero-hex check, and a
  diff secret-pattern scan all passed.
