Formulario multiline para escribir una memoria nueva. El dominio memoria usa violeta, no teal.

```jsx
<RememberForm focus rows={3} value="deepseek v3 falla con tool-use paralelo; enrutar a claude" tags="routing, deepseek" />
```

- Con foco: barra \u2503, caret y titulo en `--memory`. Hint de guardado siempre visible.
