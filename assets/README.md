# eBrain Documentation Assets

`ebrain-wordmark.svg` and `ebrain-tui-demo.svg` are generated by
`bun run scripts/generate-doc-assets.ts`.

The wordmark derives from the existing TUI pixel matrix. The TUI demo derives from the production
pure frame renderer and a sanitized repository-owned fixture. Do not replace either asset with a
personal screenshot, terminal capture, token, local path, customer identity, or live session output.
